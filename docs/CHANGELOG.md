## 2026-06-01

### 成员详情照片与墓址地图

- 个人详情抽屉新增成员照片展示：有照片时显示真实头像，无照片时继续显示姓名首字占位头像。
- 个人详情抽屉新增“上传照片 / 更换照片”入口，支持 `JPG / PNG / WebP`。
- 成员新增/编辑弹窗同步新增照片上传区，可在填写资料时直接上传或更换照片；新增成员会先保存成员再自动上传照片。
- 后端新增照片上传接口：`POST /members/{member_id}/photo`。
- 后端新增 `photo_path` 字段并自动迁移 SQLite 表结构；上传文件保存在 `data/member-photos/`，通过 `/api/member-photos/...` 访问。
- 成员档案新增 `photoUrl` 返回字段，树数据和成员列表均可读取。
- 安葬地/墓址字段新增地图选点能力：编辑成员时可搜索墓址/在地图点击位置/使用浏览器当前位置，并自动回填地址、纬度、经度。
- 个人详情中有经纬度时优先用坐标打开地图定位；无坐标时回退为按墓址文本搜索。
- Excel 导入样表新增四列：`安葬地/墓址`、`安葬纬度`、`安葬经度`、`照片地址`。

## 2026-05-30

### 世系图展示优化

- 将家谱可视化从普通树状图升级为横向家族世系图，更符合横屏查看和传统族谱阅读习惯。
- 世代按固定横向列展示，同辈保持同一竖列，避免不同代际混在一起。
- 父系主干线加粗显示，突出主线传承关系。
- 配偶关系改为在人物卡片内展示，不再单独拉复杂配偶线，降低阅读干扰。
- 新增支脉/分房淡色背景区域，并在区域右上角显示支脉名称。
- 修复支脉标签错误显示“长子 / 次女”等排行的问题，改为显示 `branch` 字段；未填写时自动使用房长姓名生成“某某支”。
- 优化支脉纵向间距：节点基础行距调整为 `178`，不同支脉之间额外增加 `92` 间距，减少第三、第四代节点拥挤。
- 增加世系图交互能力：全部展开、只看主线、展开到三世、单个节点展开/收起。

### 父系主线与配偶原生支脉修复

- 修复“孙永芳展开后，王文华支脉点击无变化”的问题。
- 后端树生成逻辑改为父系主线优先：
  - 男方主线节点可以合并配偶子女。
  - 女方作为配偶且自己有原生家庭时，不再把丈夫和子女反向塞回女方原生支脉。
- 避免同一子女被配偶原生家庭提前占用，导致父系主线节点无法正常展开。
- 验证案例：
  - `王文华 -> 王健 -> 王忆涵` 保持在王文华父系主线下。
  - `孙永芳` 仍作为王文华配偶显示，但其原生支脉不再抢占王健这一支。
  - `王健` 卡片中应显示配偶 `顾福梅`。
