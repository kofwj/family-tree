# 2026-05-25 阶段日志：生卒日期阳历/阴历双轨并轨

## 本次目标

将成员档案中的出生日期、去世日期从单一阳历字段，升级为“阳历 + 阴历 + 原始族谱记载”并轨保存与展示，避免旧族谱中的农历资料被强行转换后丢失原貌。

## 已完成内容

### 1. 后端数据模型扩展

在 `Member` / `MemberCreate` 中新增生卒日期扩展字段：

- 出生日期：
  - `birth_calendar`
  - `birth_lunar_date`
  - `birth_is_leap_month`
  - `birth_date_text`
- 去世日期：
  - `death_calendar`
  - `death_lunar_date`
  - `death_is_leap_month`
  - `death_date_text`

原有字段继续保留：

- `birth_date`
- `death_date`

### 2. SQLite 自动迁移

`MEMBER_SQLITE_EXTRA_COLUMNS` 已加入上述新增列。服务启动时会自动检查 `member` 表结构并补齐缺失字段，不需要手工改库。

### 3. API 输出与权限模板

`member_to_dict()` 已返回新增字段的前端驼峰格式：

- `birthCalendar`
- `birthLunarDate`
- `birthIsLeapMonth`
- `birthDateText`
- `deathCalendar`
- `deathLunarDate`
- `deathIsLeapMonth`
- `deathDateText`

字段可见性模板同步纳入：

- `public`：开放出生相关非敏感字段
- `archive` / `sensitive`：开放完整生卒双轨字段

### 4. 前端成员表单改造

`MemberForm.vue` 中出生/去世日期已从单一日期选择器升级为双轨录入：

- 日期类型：阳历 / 阴历 / 并轨 / 不详
- 阳历日期选择器
- 阴历日期文本输入
- 闰月开关
- 原始记载输入框

成员为“健在”时，去世日期相关输入自动禁用。

### 5. 详情抽屉展示改造

`MemberDrawer.vue` 的生命轨迹支持统一展示：

- 只有阳历：`阳历 YYYY-MM-DD`
- 只有阴历：`阴历 丁酉年腊月初三`
- 两者都有：`阳历 YYYY-MM-DD / 阴历 丁酉年腊月初三`
- 有原始记载时，在时间线中展示“原文：……”

## 设计原则

本次改造遵循：

> 原始记载不能丢；阳历用于排序计算；阴历用于族谱表达；两者并列展示。
